#sOnOs
sOnOs is an Arch Linux-based operating system designed for both developers and gamers.It aims to save you time after installation by pre-configuring popular programming languages, developer tools, and graphics drivers (such as NVIDIA) right out of the box.Note: The project is currently in Beta and under active development.FeaturesDeveloper Ready: Out-of-the-box toolchains and environments for C/C++, Python, Rust, Node.js, Go, and Java.Gaming & Driver Support: Pre-configured NVIDIA drivers, Vulkan, and GameMode for optimal performance.Arch Ecosystem: Lightweight, fast, and fully compatible with Arch repos and the AUR.Minimal & Custom: Clean desktop experience stripped of bloatware, tailored for productivity.Pre-installed PackagesCategoryPackagesDevelopmentGCC, Python, Rust, Node.js/NPM, Go, OpenJDK, Git, Micro, Neovim, VimGaming & SystemNVIDIA Drivers, Steam, Pipewire, NetworkManagerUtilitiesFastfetch, Btop, Zsh, p7zip, NTFS-3GInstallationDownload the latest .iso image from the Releases section.Flash the ISO to a USB drive using Ventoy, BalenaEtcher, or the dd command:Bashsudo dd bs=4M if=sOnOs-x86_64.iso of=/dev/sdX status=progress oflag=sync
Boot from the USB drive to launch the live environment and installer.ContributingSince sOnOs is in beta, bug reports, feedback, and pull requests are welcome. Feel free to open an issue or submit a PR on GitHub.LicenseDistributed under the GPL-2.0 License.
